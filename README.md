### About me

I'm a **PhD student in Machine Learning for Healthcare** in Prof. Björn Eskofier's group at **LMU Munich**, funded by the **Munich Center for Machine Learning (MCML)**.

Before that, I spent 18 months at **SLB** in Cambridge (MA), building ML pipelines for methane emissions monitoring. My work keeps landing in the same place: **bridging physics-based models and neural networks** to make sense of messy real-world sensor data, first for the environment, now for health.
